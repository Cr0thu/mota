# 4090 No-hp403 CPU Optimization Status

Date: 2026-05-28

## Code Optimizations

- `MotaState.clone()` no longer copies historical logs by default. This avoids repeatedly copying thousands of old log rows during MCTS/planner branching. Set `MOTA_COPY_STATE_LOGS=1` only for debugging.
- `reachable_cells()` now uses parent pointers during BFS and reconstructs paths after traversal, avoiding repeated path-list copies while expanding the grid.
- `MotaState` now carries a lightweight signature cache for floor signatures and consumed-map hash. `set_tile()` invalidates this cache whenever the map changes.
- Stage-completion caching was added behind `MOTA_ENABLE_STAGE_CACHE=1`. It is enabled in remote training scripts, but disabled by default locally so tests and manual direct map mutation remain safe.
- New staged AlphaZero option: `scripts/train_alpha_mota_stage.py --start-route ... --start-route-stop-stage sword`. This lets shield training start from the self-generated no-hp403 sword route instead of wasting each episode rediscovering the sword.
